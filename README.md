# DualSense Forever

Comfortable gamepad play in **WoW Forever**, built around the PlayStation **DualSense** (other
controllers work too). A fork of [Easy Controller - Forever](https://github.com/moust4ki/EasyControllerWowForever)
by moust4ki.

*Удобная игра на геймпаде в WoW Forever, сделано под DualSense. Описание на русском — ниже.*

## Features

- **Chat keyboard** for the gamepad: several input methods, word prediction that learns how you
  write, quick phrases.
- **Button layers**: L2 / R2 / L2+R2, hold and double-press actions on any button.
- **Wheels**: radial menus for consumables, quest items, class spells and your own sets.
- **Touchpad corners**: the DualSense touchpad as extra buttons with their own modifiers.
- **Bags made for a controller**: the game's look, sections, search, sorting, split a stack, bind
  an item to the action bar, junk selling, the bank.
- **Light bar and vibration**: health and state on the controller itself.
- **Back paddles**: DualSense Edge and other controllers with paddles.
- **Profiles and settings sharing**: export your setup as a line of text, import it on another PC.
- **Setup guide** on first start.

Interface languages: Russian and English in full; French, German, Spanish and Italian partly.

## Installation

Install from CurseForge, or download the archive and put the `DualsenseForever` folder into
`World of Warcraft\_forever_\Interface\AddOns\`.

In game: **/ec** opens the settings, **/ec help** lists the commands.

## На русском

**DualSense Forever** — удобная игра на геймпаде в WoW Forever, сделано под DualSense (работает и
с другими геймпадами). Основан на Easy Controller от moust4ki.

- **Клавиатура чата** для геймпада: несколько способов ввода, подсказки слов, быстрые фразы.
- **Слои кнопок**: L2 / R2 / L2+R2, удержание и двойное нажатие на любой кнопке.
- **Колёса**: расходники, предметы заданий, заклинания класса и свои наборы.
- **Углы сенсора**: тачпад DualSense как дополнительные кнопки.
- **Сумки под геймпад**: вид как у игры, разделы, поиск, сортировка, разделение стаков, привязка к
  панели, продажа хлама, банк.
- **Подсветка и вибрация**: здоровье и состояние прямо на геймпаде.
- **Задние лепестки**: DualSense Edge и другие геймпады с лепестками.
- **Профили и обмен настройками**: строкой текста между компьютерами.
- **Мастер настройки** при первом запуске.

Установка: через CurseForge, или распакуйте папку `DualsenseForever` в
`World of Warcraft\_forever_\Interface\AddOns\`. В игре: **/ec** — настройки, **/ec help** — команды.
